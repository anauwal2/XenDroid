# Custom fork — FIFA Street (2012) direct-play build

Fork of [rfandango/XenDroid](https://github.com/rfandango/XenDroid), built for a
Galaxy Z Fold 6 (SM-F956B / Snapdragon 8 Gen 3 / Adreno 750).

Goal: an all-in-one APK — bundled GPU driver, tuned per-game config, and a
simplified direct-play UI.

Upstream has **no license file**, so this fork is for personal use only and is
not redistributed.

## Baseline

This commit is unmodified upstream plus this note, used to validate that the
GitHub Actions build pipeline works before any feature changes land.
